# 没有编号（no-number）

一个只有读本子才能玩下去的文字小游戏。标准库单文件，`python notebook.py` 就能跑。

> 你每次醒来都不记得上一局。本子上只剩三页，上一轮的你把要紧的话写在那儿。
> 问题是：有人也在往本子上写，而且写得比你好听。

## 跑

```
python notebook.py            # 开一局
python notebook.py --seed 7   # 固定布局
python notebook.py --debug    # 作弊：站在有原话的屋里会提示
python notebook.py --plain    # 关掉颜色
```

Windows 上双击 `没有编号.bat` 也行（需要 PATH 里有 python）。

## 规则

- 十四次醒来。用完就没了。
- 本子只有三页。写新的，挤掉最旧的。
- 三张「原话」散在九间屋子里。集齐三张、走回门厅，后门才开。
- 原话占本子的页，而且挤不掉 —— 所以你得替它腾地方。
- 每三次醒来，有人替你写一页。那页看着像你写的，其实不是。验一下才现形，撕下来能腾回一页。

动作：`n/s/e/w`（或 `北南东西`）走一步、`写 <一句话>`、`验 <页码>`、`看`（免费）、`退`。
走路、写字、验墨迹各花掉一次醒来。

## 结局

七个，按你走到哪一步判，不是按分数：

| | 名字 | 什么时候 |
|---|---|---|
| A | 压痕 | 后门开了，而且你写过字 |
| B | 三张别人的话 | 后门开了，你一句没写 |
| C | 最好听的那一页 | 输了，本子里还躺着一页你从来没验过的字 |
| D | 指缝里的纸 | 输了，撕过假页，缺的那张原话没走到 |
| E | 差几步 | 原话齐了，人还在外面，一次也没试着往满页上写 |
| F | 纸外面 | 原话齐了，人还在外面，而且你想写、写不进去 |
| G | 挤掉的那几页 | 输了，假页被后来的页挤掉了，你一页也没验 |

C 和 G 的分界是「有没有验过」：验了 → D，没验但被挤掉 → G，没验还躺在本子里 → C。

## 已知问题（v0.1，还没改）

**这游戏的机制目前不咬人。** 一条固定的十步路线（`n n e e s w s e w w`）扫遍九间屋子，300 个种子 300 次全胜：
不用写一个字，不用验一页，醒来预算和三页纸从来没成为约束。也就是说，它现在更像「走迷宫」，而不是
「你的记忆只有三页」。

这是 v0.2 要做的事，候选方向（写在 issues 里，别悄悄改）：

1. 原话不自动抄进本子 —— 拿到纸只是「看见」，得自己 `写` 一次抄下来，花一次醒来。不抄，出了这间屋子就忘了。
2. 假页会挤掉你还没锁的笔记。
3. 醒来预算收紧到刚好够用，让「先抄哪张、先验哪页」变成真的选择题。

平衡改动请提 issue，别直接改代码 —— 文本、节奏和难度是一件事的三个面。

## 开发

这台机器上 `git push https://github.com/...` 连不上（443 超时），只有 `api.github.com` 通。
所以本地照常用 git 提交，推上去走脚本：

```
node tools/push.mjs "提交说明"
```

它用 git data API 把工作区整个推成一个提交（token 取 `GH_TOKEN` 或 `%USERPROFILE%\.bili-ai\github.json`）。
`git push` 哪天通了，就换回 `git push origin main`，脚本留着当备胎。

CI 在 `.github/workflows/test.yml`：每次推都跑一遍 `test_notebook.py` 和 `demo.py`。
