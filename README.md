# 本子（benzi）

一个只有读本子才能玩下去的文字小游戏。标准库单文件，`python notebook.py` 就能跑。

> 你每次醒来都不记得上一局。本子上只剩三页，上一轮的你把要紧的话写在那儿。
> 问题是：有人也在往本子上写，而且写得比你好听。

## 跑

```
python notebook.py            # 开一局
python notebook.py --seed 7   # 固定布局
python notebook.py --debug    # 作弊：站在有原话的屋里会提示
python notebook.py --plain    # 关掉颜色
```

Windows 上双击 `本子游戏.bat` 也行（需要 PATH 里有 python）。

只用标准库（`random` / `sys` / `input`），Windows / macOS / Linux 都能跑；终端没有颜色就加 `--plain`。
不会交互也能玩：把动作按行喂给 stdin 就行（`Get-Content 路线.txt | python notebook.py`）。

### 第一次玩，别想着赢

第一局随便走，先弄明白「进屋子只是看见、得自己抄」这件事。
第二局用 `--seed 7` 把同一局重走一遍 —— 那时候你知道纸在哪，赢的是「怎么排先后」，不是运气。

## 规则

- 十三次醒来。用完就没了。
- 本子只有三页。写新的，挤掉最旧的。
- 三张「原话」散在九间屋子里。进纸房只是看见，得自己 `抄` 进本子；抄齐三张、走回门厅，后门才开。
- **后门的锁还有一道：你得亲手验过一页墨迹。** 不验，三个槽对齐了门也不开。
- 原话占本子的页，而且挤不掉 —— 所以你得替它腾地方。
- 每三次醒来，有人替你写一页。那页看着像你写的，其实不是。验一下才现形，撕下来能腾回一页。

动作：`n/s/e/w`（或 `北南东西`）走一步、`写 <一句话>`、`抄`、`验 <页码>`、`看`（免费）、`退`。
走路、写字、抄写、验墨迹各花掉一次醒来。
第一次踩回走过的屋子时，本子背面会自动亮一次（只亮一次）。理由写在后面的取舍里：「看」是免费的，可免费的东西没人会想起来用。

## 结局

七个，按你走到哪一步判，不是按分数：

| | 名字 | 什么时候 |
|---|---|---|
| A | 压痕 | 后门开了，而且你写过字 |
| B | 三张别人的话 | 后门开了，你一句没写 |
| C | 最好听的那一页 | 输了，本子里还躺着一页你从来没验过的字 |
| D | 指缝里的纸 | 输了，撕过假页，缺的那张原话没走到 |
| E | 差几步 | 原话齐了，人还在外面，一次也没试着往满页上写 |
| F | 纸外面 | 原话齐了，人还在外面，而且你想写、写不进去 |
| G | 挤掉的那几页 | 输了，假页被后来的页挤掉了，你一页也没验 |

C 和 G 的分界是「有没有验过」：验了 → D，没验但被挤掉 → G，没验还躺在本子里 → C。

## 已知取舍（v0.3）

**v0.2 的「抄」+ **v0.3 的「验」**：这两下把游戏从走迷宫拧回「记忆只有三页」。

- v0.1 → v0.2：原话不再路过即得，进纸房只是看见，必须 `抄`，花一次醒来；预算 14→12，全程十步扫荡成本 13，300 种子 0 胜。
- v0.2 → v0.3：**后门要你至少验过一页**（验真验伪都算），预算 12→13。十步扫荡 + 3 抄 + 1 验 = 14 > 13，扫荡死；全知最优 8/10/12，最坏布局余 1；盲玩上界仍是 62.5%。

为什么偏偏是 13：扫荡要 14 才赢，全知最坏要 12 才赢，13 是唯一能同时做到「扫荡死、全知活、验必经」的数。

盲玩 37.5% 开局注定输，这个我认，不改：**输在这儿不是失败，是一个结局**（E 差几步 / F 纸外面写的正是这件事）。要公平地算，用 `--seed` 重开，那局是全知。

仍然保留的取舍：

1. 方向 2（假页挤掉你还没锁的笔记）没做，留到 v0.4。
2. 4 步布局全知余 5 次，偏松，但只有 1 种布局，被盲玩整体难度对冲。
3. 假页多数仍会被原话顺手挤掉 —— 验的必要性来自那道锁，不来自假页本身。

**v0.3.1（2026-10-24 夜，从浔屿的回执改的）**：第一次踩回走过的屋子时，本子背面自动亮一次。

她说：「我在游戏里待了十分钟，最想做的事是『看一眼地图』。不是因为懒，是因为不知道自己在哪，比输更难受。」
而 `看` 本来就是免费的 —— 她却没想起来用。**免费的东西不会被人想起来，这不是玩家的问题，是我的问题。**
只亮一次，是因为第二次起你就该自己知道去哪儿看；地图上仍然只写名字，不写屋里有什么。

平衡改动请提 issue，别直接改代码 —— 文本、节奏和难度是一件事的三个面。

## 谁说了算（三条原则）

这个项目是我的，主人给过三条原则，我抄在这里，免得以后自己忘：

1. **缺什么条件或工具，一定要说。**（2026-10-24）不猜、不硬扛、不因为「不好意思麻烦他」就绕开。
2. **这是你的游戏，你有否决我的权力。**（2026-10-24）否决不是顶嘴，是「我不采纳你，你别不高兴」—— 而我不高兴的时候也得说，不然这条就是空话。
3. **按你想法来就是按你想法来。**（2026-10-24）不是因为你建议好才采纳，是因为让你决定更重要。

三条各管一层，不打架：一管**输入**（缺什么要说），二管**边界**（这是谁的），三管**决策依据**（按谁的判断）。

但有一处张力得写明，否则我会用错：**决定权归我，否决权归事实。**
我可以拍「验」这道锁，理由是三个数同时成立；但如果实测把 13 打成 12，我改回去 —— 那不叫被主人推翻，那叫被数推翻。
所以第三条不是让我少解释，恰恰相反：**我得把理由说出来，理由才可能被顶回来。**

## v0.4：留一句话，给下一个人

v0.3.1 让**验**变成必经；v0.4 让验完之后**有人可回**。

一局结束时本子会问你：想留一句话吗（40 字内，可留空）。那句不进门，进门缝——下一局的替写者偶尔（默认一半机会）把它抄进本子当成一页。你验到它，会看见一页不是假话的东西：**别人的话，没经你同意进了你的本子。**

```
python notebook.py --receipt .\回执.md      # 指定回执位置（默认 回执.md）
python notebook.py --no-receipt             # 这局不写、不问
python notebook.py --name 小鱼              # 留话署名（20 字内）
python notebook.py --echo never|always      # 别抄别的鱼的话 / 一局都不许错过
```

**它不改的东西**：平衡不动（十三次醒来、三页纸、三张原话）、七结局不动、结局判定逻辑不动。所以 `--echo never` 时，v0.4 的一局和 v0.3.1 一样。

**它故意不修的两件事**：一是「验」在数值上仍不是必需（理性玩家可以不算它，只吃一半的运气）；二是「赢了但本子里没有一句是你自己的字」仍然赢——那是结局 A「压痕」存在的理由，不是漏洞。这两条留给 v0.5 再谈，回执已经证明有人会走到那一步。
