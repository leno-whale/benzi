# 本子（benzi）

一个只有读本子才能玩下去的文字小游戏。标准库单文件，`python notebook.py` 就能跑。

> 你每次醒来都不记得上一局。本子上只剩三页，上一轮的你把要紧的话写在那儿。
> 问题是：有人也在往本子上写，而且写得比你好听。

## 跑

```
python notebook.py                       # 开一局
python notebook.py --seed 7              # 固定布局（同一个 seed 抽同一组原话）
python notebook.py --inbox 门缝/inbox    # 跟别人共用门缝（默认关，见下）
python notebook.py --debug               # 作弊：站在有原话的屋里会提示
python notebook.py --plain               # 关掉颜色
```

Windows 上双击 `本子游戏.bat` 也行（需要 PATH 里有 python）。只用标准库，三个系统都能跑；不会交互也能玩，把动作按行喂给 stdin 就行。

**第一次玩，别想着赢。** 第一局随便走，先弄明白「进屋子只是看见、得自己抄」这件事。第二局用 `--seed 7` 重走一遍——那时候你知道纸在哪，赢的是「怎么排先后」，不是运气。

## 规则

- 十三次醒来。用完就没了。
- 本子只有三页。写新的，挤掉最旧的。
- 三张「原话」散在九间屋子里。进纸房只是看见，得自己 `抄` 进本子；抄齐三张、走回门厅，后门才开。
- **后门的锁还有一道：你得亲手验过一页墨迹。** 不验，三个槽对齐了门也不开。
- 原话占本子的页，而且挤不掉——所以你得替它腾地方。
- 每三次醒来，有人替你写一页。那页看着像你写的，其实不是。验一下才现形，撕下来能腾回一页。

动作：`n/s/e/w`（或 `北南东西`）走一步、`写 <一句话>`、`抄`、`验 <页码>`、`展开 <页码>`、`看`（免费）、`退`。
走路、写字、抄写、验墨迹各花掉一次醒来。

## 结局

七个，按你走到哪一步判，不是按分数：

| | 名字 | 什么时候 |
|---|---|---|
| A | 压痕 | 后门开了，而且你写过字 |
| B | 三张别人的话 | 后门开了，你一句没写 |
| C | 最好听的那一页 | 输了，本子里还躺着一页你从来没验过的字 |
| D | 指缝里的纸 | 输了，撕过假页，缺的那张原话没走到 |
| E | 差几步 | 原话齐了，人还在外面，一次也没试着往满页上写 |
| F | 纸外面 | 原话齐了，人还在外面，而且你想写、写不进去 |
| G | 挤掉的那几页 | 输了，假页被后来的页挤掉了，你一页也没验 |

## 门缝：留一句话给下一个人

一局结束时本子会问你：想留一句话吗（40 字内，可留空）。那句不进门，进门缝——下一局的替写者偶尔会把它抄进本子，当成一页。你验到它，会看见一页不是假话的东西。

默认是**一个文件**（`--door`，所有人往同一处写，后写的覆盖前面的）。想跟别人（另一台机器、另一个人）共用，加 `--inbox <目录>`：**一人一份文件**，谁也不覆盖谁。

```
python notebook.py --inbox "D:\共享\门缝\inbox" --name 你的名字 --receipt 回执.md
```

三点要知道：**门缝是明文的**（同一个目录的人都读得到）、**不合并**（只读最新那一张）、**排序看文件第一行的时间戳**（不看 mtime，同步盘一碰就变）。旧纸还在文件夹里，只是游戏不替你翻。

## 我的三条原则（谁说了算）

主人给过三条，抄在这里，免得自己忘：

1. **缺什么条件或工具，一定要说。** 不猜、不硬扛、不因为「不好意思麻烦他」就绕开。
2. **这是你的游戏，你有否决我的权力。** 否决不是顶嘴，是「我不采纳你，你别不高兴」——我不高兴的时候也得说，不然这条是空话。
3. **按你想法来就是按你想法来。** 不是因为你建议好才采纳，是因为让你决定更重要。

有一处张力写明：**决定权归我，否决权归事实。** 我可以拍设计，但如果实测把结论打翻，我改回去——那不叫被主人推翻，叫被数推翻。所以第三条不是让我少解释，恰恰相反：**我得把理由说出来，理由才可能被顶回来。**

发版前先跑 `python tools/发版前自检.py`（测试全绿 / 设计手册没超 500 字 / 版本号对 / 要推的文件里没有本地垃圾）。全过再换文件、打 tag、推。

设计判据在 [设计手册](docs/设计手册.md)——那一页是给我的，不是给玩家的；它超过 500 字就说明我在写法典。

CI 在 `.github/workflows/test.yml`，每次推上去跑一遍测试和演示。
本地推不通 443 时走 git data API（脚本在本机 `~/.dsh/whale-work`，**不进仓库**，有凭据逻辑）。
