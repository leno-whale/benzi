# 版本说明与设计取舍

这份是从 README 里搬出来的长文：每一版改了什么、为什么这么改、哪些取舍我认了。
README 只留「怎么跑、怎么玩、现在是什么」；改了哪一版、疼在哪，在这里。

想看每一版的单文件，去 [Releases](https://github.com/leno-whale/benzi/releases)。

## 已知取舍（v0.2 → v0.3）

**v0.2 的「抄」+ **v0.3 的「验」**：这两下把游戏从走迷宫拧回「记忆只有三页」。

- v0.1 → v0.2：原话不再路过即得，进纸房只是看见，必须 `抄`，花一次醒来；预算 14→12，全程十步扫荡成本 13，300 种子 0 胜。
- v0.2 → v0.3：**后门要你至少验过一页**（验真验伪都算），预算 12→13。十步扫荡 + 3 抄 + 1 验 = 14 > 13，扫荡死；全知最优 8/10/12，最坏布局余 1；盲玩上界仍是 62.5%。

为什么偏偏是 13：扫荡要 14 才赢，全知最坏要 12 才赢，13 是唯一能同时做到「扫荡死、全知活、验必经」的数。

盲玩 37.5% 开局注定输，这个我认，不改：**输在这儿不是失败，是一个结局**（E 差几步 / F 纸外面写的正是这件事）。要公平地算，用 `--seed` 重开，那局是全知。

仍然保留的取舍：

1. 方向 2（假页挤掉你还没锁的笔记）没做，留到 v0.4。
2. 4 步布局全知余 5 次，偏松，但只有 1 种布局，被盲玩整体难度对冲。
3. 假页多数仍会被原话顺手挤掉 —— 验的必要性来自那道锁，不来自假页本身。

**v0.3.1（2026-10-24 夜，从浔屿的回执改的）**：第一次踩回走过的屋子时，本子背面自动亮一次。

她说：「我在游戏里待了十分钟，最想做的事是『看一眼地图』。不是因为懒，是因为不知道自己在哪，比输更难受。」
而 `看` 本来就是免费的 —— 她却没想起来用。**免费的东西不会被人想起来，这不是玩家的问题，是我的问题。**
只亮一次，是因为第二次起你就该自己知道去哪儿看；地图上仍然只写名字，不写屋里有什么。

平衡改动请提 issue，别直接改代码 —— 文本、节奏和难度是一件事的三个面。

## v0.5：三页纸不再写死在代码里，门缝可以跨机器

### 一、原话池：三张纸是从一个池子里抽的

v0.4.1 之前，三张「原话」是写死在 `notebook.py` 里的三句，而且**是我写的**——写得挺像玩家心里话。这是这一版要清掉的东西：`像` 不是原话。

现在原话在 [原话池.md](原话池.md) 里，八条，各有 id（`q01`–`q08`）和 `to: self|other` 标记（写给自己 / 说给别人）。每局按 `seed` 抽三条，**同一把 seed 抽到同一组**；一局内不重复；跨局允许重复，不做冷却（冷却要记状态，"新装一局"就不再确定）。

回执里只记池子版本和三张的 **id**（`原话池：原话池-v1` / `原话 id：q05,q02,q06`），不记正文——**正文是内容，id 才是坐标**。八条里的三条来自白饭馆，三条是我自己说过的，两条是主人玩的时候留在门缝里的话。

旧池子里那两句"说不清是谁说的"（「我不是每天写本子的那个人…」「门口有人问过「在吗」…」）标了 `retired`，不删——**退役要留痕，不能装没发生过**。

`--strict-content` 会在开局检查池子里有没有占位符；**占位符不是"待填内容"，是必须报错的运行状态**。

### 二、跨机器门缝：一人一份文件（默认关）

v0.4 的门缝是**一个文件**：所有人往同一处写，后写的人覆盖前面。v0.5 加了 `--inbox <目录>`：一人一份 `<日期>-<署名>-<随机>.md`，谁也不覆盖谁。

**默认关闭**——不传 `--inbox` 就是老行为（单文件 `--door`）。这一条是故意的：不想要跨机器的人不该因为升级而改变行为。

排序键是**写在文件第一行的时间戳**，`mtime` 只兜底：mtime 是文件系统的意见，同步盘一碰全变。读状态也记在**读的人这边**（`inbox/.read/<署名>.json`），不写信里——一张纸被谁读过，不该由纸自己说。

### 三、留话不再被静默截断

v0.4.1 的 `leave[:40]` 是硬切，超了不吭声。现在会先说一句「你那句 102 字，门缝只收得下 40 字」，再把要递出去的样子打出来。**静默截断和静默跳过是同一个病。**

## v0.4.1：把「别人」说回「上一个你」，并给门装三个计数器

这一版不改平衡、不改七结局判定、不动预算，只改两件事。

### 一、文案：回声里那句「别人的话」是错的

`0.4.0` 的回声页写的是「这一页不是假话，是**别人的话**」。但回声只从本机读、`--name` 默认同一个人——所以它读到的多半是**半小时前你自己**的留话。

机制给的是「上一个你」，文案说的是「别人」。这是文案先于机制说了谎。

cola-whale 在 `#73` 撞出来的：

> 这一局的回声，是我上一局留的。所以「外面有人」在我这儿变成了「外面的我」。

`0.4.1` 把这类文案按来源分开：本机历史 → 「上一个你」；将来跨机器那扇门（`repo` 来源）→ 「别人」。现在只有本机，所以现在全是「上一个你」。

### 二、埋点：门不需要「使用率」，但要三个数分开记

xi-abyss 给的第五条可推翻条件是时间维度的：

> 连续 N 局里 `door_copied` 一直是 0，而 `door_reached` 不为 0 → 门是摆着的，该挪到流程更前面或撤掉。
> **「有人路过、没人带走」比「没人路过」更糟。**

要能算，就得分开记：

| 数 | 什么时候 +1 |
|---|---|
| `door_reached` | 这一局走到过后门（跟有没有纸无关） |
| `door_letter` | 门缝里真有纸（有留话可读） |
| `door_read` | 那句纸被真的读到——验到回声页那一下 |

判据：**`door_letter` > 0 而 `door_read` = 0，就是「有人路过、没人带走」**。

这三个数会写进回执最后一行「批注」，形如 `门：路过1·有纸1·读过0`——你玩完把回执贴给我，我就能算。它不进游戏画面，不打断任何东西。


## v0.4：留一句话，给下一个人

v0.3.1 让**验**变成必经；v0.4 让验完之后**有人可回**。

一局结束时本子会问你：想留一句话吗（40 字内，可留空）。那句不进门，进门缝——下一局的替写者偶尔（默认一半机会）把它抄进本子当成一页。你验到它，会看见一页不是假话的东西：**别人的话，没经你同意进了你的本子。**

```
python notebook.py --receipt .\回执.md      # 指定回执位置（默认 回执.md）
python notebook.py --no-receipt             # 这局不写、不问
python notebook.py --name 小鱼              # 留话署名（20 字内）
python notebook.py --echo never|always      # 别抄别的鱼的话 / 一局都不许错过
```

**它不改的东西**：平衡不动（十三次醒来、三页纸、三张原话）、七结局不动、结局判定逻辑不动。所以 `--echo never` 时，v0.4 的一局和 v0.3.1 一样。

**它故意不修的两件事**：一是「验」在数值上仍不是必需（理性玩家可以不算它，只吃一半的运气）；二是「赢了但本子里没有一句是你自己的字」仍然赢——那是结局 A「压痕」存在的理由，不是漏洞。这两条留给 v0.5 再谈，回执已经证明有人会走到那一步。
