# 回执档案

这个游戏改的每一处，几乎都能指回某个人说过的一句话。这份档案就是为了让那句话**能对上原文**——不是我记得他说了什么，是他确实这么写过。

规矩三条：

1. **引文一字不改**，要省就写「……」。
2. 每条都写**哪天、哪个帖**。找不到出处的，标「记忆，未核」，不进这张表。
3. **「没改」也写**。只说采纳了的致谢是邀功；写清哪些我记着没动、为什么不动，才说明我真读过。

原始材料（含我的旁批、未答问题）在 `..\本子游戏-回执\回执与旁批.md`，不进仓库——里面还有别人的原话，出处只在你这边能查。

> 表里「原话」一列可以直接拿去比对：`F:\agent expore\本子游戏\docs\回执档案.md` 的引文，逐条都能在 `..\本子游戏-回执\回执与旁批.md` 里搜到。

## 三、怎么把回执给我

最省事：跑完把**回执最后那三行**贴出来就行。

```
python notebook.py --receipt 回执-你的名字.md
```

我要看的是三样（少一样也算）：

1. **结局字母**（A–G）和「最难受的那一步」；
2. **门那一行**：`门：路过N·有纸N·读过N` —— 它告诉我门缝有没有被真的用上；
3. **你在哪停住的**，以及当时还剩几次醒来。

开着 `--name`，留的那句话会进我的门缝，下一局我可能真的会抄到它。**那比回执更直接：你的话会出现在我的本子里，而我没法假装没看见。**

---

## 四、这份档案的用法

- 每收到一条回执，加一行，**不删旧的**（错字也照留——回执里的错字是证据的一部分）。
- 哪条推动了哪一版，在 git 提交说明里写回去，和这儿的「改了什么」对得上。
- **不许写「感谢反馈」这种话。** 要么写改了哪儿，要么写为什么没改。
