# 《本子》v0.5 顶层架构

> 架构员方案（A：最小改动，延续 v0.4 的「独立存储器 + Notebook 薄钩子」），领航员按 2026-10-26 拍板整理。
> 基线：根目录 `notebook.py` v0.4.1（939 行）。所有 v0.5 文件只放 `v0.5/`，不改根目录。

## 一、目标与非目标

v0.5 只加四件：门缝并档、回执自动打标、折叠、未定位。

不改：`WAKES=13`、`PAGES=3`、三张原话、七结局 A–G 判定、后门「三原话 + 回门厅 + 验过一页」、地图提示、回执/留话/回声。

不做：第八结局、挪后门、印章/签名、每人一个门缝文件、把时长当判据。

## 二、三个候选

| 方案 | 做法 | 评价 |
|---|---|---|
| A 独立存储器 + 薄钩子 | 新增 `DoorStore`，`Notebook` 加 `folded/ever_folded/full_text/gist` 页字段、`fold()`/`unfold()`、`unlocated`、`clock`；回执 `make_entry` 加字段 | **采用**。旧 204 项可零改动，折叠/门缝/打标各自隔离 |

## 四、Notebook

```python
Notebook(seed=None, debug=False, receipt=None, name="你", echo="auto",
         door=None, clock=None, fold=False)
```

- `fold=False` 是 API 默认：旧测试 `Notebook(seed)` 行为与 v0.4.1 完全一致。
- `main()` 传 `fold=True`；`--no-fold` 关掉。
- `receipt=None`、`door=None` 默认不读写；`main()` 才设默认路径。
- `clock` 默认 `time.monotonic`，测试注入固定时钟；`datetime.now` 只用于回执 ts。

页字段：

```python
{"text", "ink", "real", "piece", "echo",
 "folded": False, "ever_folded": False, "full_text": None, "gist": None}
```

`text` 是玩家当前看到的文本；折起时替换为 `（折起来的一页。大意：…）`，`full_text` 存原文。

## 五、折叠状态机

- 触发：`next_round()` 先按 v0.4.1 推假页/回声，再 `if fold_enabled and round % 4 == 0: _fold_oldest()`。
- 候选：`not piece and not ever_folded` 的最旧页；没有则 no-op。
- 动作：`folded=True`、`ever_folded=True`、`full_text=原文`、`gist=清洗后前 12 字 + "……"`，`text` 改为折叠显示；`log` 记 `("fold", round, page_no)`。
- `unfold`：花 1 醒来，`folded=False`、`text=full_text`，`ever_folded` 保留，`gist` 不重算；推进回合。
- `verify` 折起页：不花醒来、不记 caught，提示「折着，验不了」。
- 原话 `piece=True` 永不折；折起页被挤掉按普通页处理。

关键顺序：`push` 可能挤掉一页，所以必须先 push 再 fold；fold 只折 push 之后仍在的页。第 12 次醒来同时命中假页和折叠时，先假页、后折叠。

## 六、门缝

- 路径：默认 `v0.5/门缝/留话.txt`，`--door PATH` 覆盖；`--no-receipt` 一并关闭。
- 格式：UTF-8 纯文本、无文件头、每行一条、append-only、**最新在最后一行**；读最后一条非空行。
- 理由：多人/多进程并发只追加，避免「最新在上」的全量重写丢写。
- 游戏内只显示「门缝里的纸」「最近塞进去的那张」，不打印绝对路径；文件路径只打印 basename。
- 回声优先读门缝；门缝空时回落自己的回执（兼容 v0.4 旧档）。

## 七、回执字段

条目头：`## {ts} · {who}`；字段顺序：

```
- seed
- 结局：{code} · {title}
- 原话
- 留话
- 批注
- 版本：0.5
- 时长：X 分 Y 秒
- 醒来用在哪：走 N · 写 N · 抄 N · 验 N · 展开 N
- 门：路过 N · 有纸 N · 读过 N
- 未定位：N 条
```

- 新四行只在本局有打标时写；v0.5 正常结束总会写。
- 旧条目缺四行照常解析；`我的批注` 兼容为 `批注`。
- 写失败只警告，不影响结局。

## 八、CLI

```
python notebook_v05.py [--seed N] [--debug] [--plain]
  [--name 谁] [--echo auto|always|never]
  [--receipt PATH] [--no-receipt] [--door PATH]
  [--inbox DIR] [--pool PATH] [--strict-content]
  [--no-fold] [--version]
```

- TTY 默认开回执 + 门缝；非 TTY 默认关，显式 `--receipt PATH` 才开。
- `--no-receipt` 优先：回执、门缝、留话、回声全关；折叠/没记仍生效。
- `--door` 只覆盖单文件路径；`--inbox` 使用跨机器目录，两者同时给时 inbox 优先。
- `--pool` 换原话池；`--strict-content` 遇到占位池退出 2。
- `--version` 打印 `本子 v0.5`。

## 十、风险

1. 一页只折一次会让后半局折叠变稀；第 12 次可能无页可折，这是接受的设计，不拿「折两次」补。
2. `ever_folded` 若被 `展开` 清掉会变成可折两次；验收专跑「展开后再到第 8 次」。
3. 回声页可被折，验回声变成「先展开再验」，更贵；这是折叠的代价，写入玩法。
4. 门缝并档没有私密性；同一台机器上的人互相看得到留话，只承认、不假装解决。
5. 时长含挂机；只作事实，不判人、不给奖励、不进结局。
