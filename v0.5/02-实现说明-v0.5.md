## 二、实现范围

v0.5 只加四层：

1. **折叠 / 展开**：每 4 次醒来折一页最旧的非原话页；折起页只能读大意、验不了；展开花 1 次醒来。
2. **未定位**：`没记 <话>` 免费、不推进、最多 5 条；进结算与回执，不写进本子。
3. **门缝并档**：独立 `DoorStore`，多人共用一个纯文本 append-only 文件；回声优先读门缝，空则回落自己回执。
4. **回执打标**：时长、醒来用在哪、门计数、未定位；旧回执缺行照常解析。

不动：`WAKES=13`、`PAGES=3`、三张原话、七结局 A–G 判定、后门「三原话 + 回门厅 + 验过一页」、假页 3/6/9/12、地图、方向别名。

## 三、API 与状态

```python
Notebook(seed=None, debug=False, receipt=None, name="你", echo="auto",
         door=None, clock=None, fold=False)
```

- `fold=False` 是 API 默认，旧调用 `Notebook(seed)` 行为与 v0.4.1 一致。
- `main()` 默认 `fold=True`；`--no-fold` 关闭。
- `receipt=None` / `door=None` 默认不读写；`main()` 才设默认路径。
- `clock` 默认 `time.monotonic`，测试注入固定时钟；`datetime.now` 只用于回执 `ts`。

页字段：

```python
{"text", "ink", "real", "piece", "echo",
 "folded": False, "ever_folded": False, "full_text": None, "gist": None}
```

- `text` 是当前显示文本；折起时换成「（折起来的一页。大意：…）」。
- `full_text` 存原文；`gist` 是清洗后前 12 字 + `……`。
- `ever_folded` 展开后仍保留，确保同一页不折第二次。
- 原话页 `piece=True` 永不折。

其他新增状态：

```python
self.fold_enabled        # API 默认 False
self.unlocated = []      # 未定位，最多 5 条
self.wake_marks = {"walk":0,"write":0,"copy":0,"verify":0,"unfold":0}
self.door_reached / door_letter / door_read
self._clock / self._start_clock
```

## 四、主要改动点

### 4.1 常量与路径

```python
VERSION = "0.5"
SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))
DEFAULT_PATH = os.path.join(SCRIPT_DIR, "回执.md")
DEFAULT_DOOR_PATH = os.path.join(SCRIPT_DIR, "门缝", "留话.txt")
```

- `ECHO_SALT`、`WAKES`、`PAGES`、`PIECES_NEEDED`、`ROOMS`、`PIECES`、`FAKES`、`ENDINGS`、`TITLES` 保持 v0.4.1。
- 默认路径在脚本目录，不再依赖当前工作目录。

### 4.2 `ReceiptStore`（沿用 v0.4.1）

- `load()` 解析 `## ` 条目；坏条目跳过；`latest_line()` 取最近一条非空留话。
- `append()` 原子写（同目录 tmp + `os.replace`）；只有文件头时不会重复写头；写失败只警告，不打印绝对路径。
- 新字段写在 `- 版本` 之后：`时长` / `醒来用在哪` / `门` / `未定位`。

### 4.3 `DoorStore`（新增）

```python
class DoorStore:
    def __init__(self, path, enabled=True)
    def load(self)          # 纯文本，每行一条，跳过空行/坏行
    def latest_line(self)   # 最后一条非空行；无则 None
    def append(self, line)  # 一行一条，append-only；自动建父目录
```

- 格式：UTF-8、无文件头、最新在**最后一行**；多进程/多次追加不会因「最新在上」的全量重写丢写。
- 不写时间戳、seed 等元数据；只存玩家留下的原话。
- 默认 `v0.5/门缝/留话.txt`；`--door PATH` 只覆盖路径。
- `--no-receipt` 时 `door=None`，门缝、留话、回声全关。
- 没有文件锁：只保证追加，不保证并发顺序（单机单人无影响）。

### 4.4 `make_entry`

```python
make_entry(seed, code, title, quote, leave, name="你", version=VERSION,
           note="", duration="", wake_usage="", door_usage="", unlocated=0)
```

- 新字段只在传入时写；旧调用不产生这四行，旧断言不变。
- `unlocated` 是整数；写入为 `- 未定位：N 条`。
- `name` 清洗后截断到 20 字。
- v0.5 `finish()` 正常结束总会传四行。

### 4.5 折叠

`next_round()`：

1. 回合 +1；超过 13 判负。
2. 3/6/9/12 推替写页/回声。
3. `if fold_enabled and round % 4 == 0: _fold_oldest()`。

`_fold_oldest()`：

- 候选：`not piece and not ever_folded` 的最旧页。
- 没有候选就 no-op；不找第二张、不折第二次。
- 折起：`folded=True`、`ever_folded=True`、`full_text=text`、`gist=前12字+……`、`text` 换折叠显示。
- 记 `("fold", round, page_no)`。

`unfold(i)`：

- 只能展开 `folded` 页；花 1 醒来，`wake_marks["unfold"] += 1`；推进回合（可能触发假页/折叠）。
- `folded=False`、`text=full_text`；`ever_folded` 保留；`gist` 不重算。
- 展开后可以验；折痕留着。

`verify(i)`：

- 折起页直接返回 `False`，不花醒来、不记 `caught`，提示「折着，验不了」。

顺序：先 push 可能挤页，再 fold；所以 fold 只折 push 后仍在的页。第 12 次同时命中假页和折叠时，先假页、后折叠。

### 4.6 未定位

`note_unlocated(text)`：

- `_one_line` 清洗；空串拒绝。
- 不花醒来、不推进回合。
- 最多 5 条；第 6 条挤掉最早。
- 写入 `self.unlocated`，不写 `pages`，不影响胜负。
- `report()` 显示条数；`finish()` 写进回执。

### 4.7 门缝、留话、回声

- 每局结束 `finish()` 顺序：结局 → 结算 → 报告 → 留话 → 写回执 → 写门缝 → 提示 basename。
- 只有 `receipt` 启用才询问留话；`--no-receipt` 不询问。
- 留话最多 40 字；EOF/Ctrl-C 视为不留；不留也写回执，但不写门缝。
- 回声：`Notebook.__init__` 读 `_door_line()`（门缝优先，空则回落自己的回执），独立 RNG 选 3/6/9/12 中的一次；`next_round` 把该次替写页换成回声原文。
- 回声页 `real=False`、`piece=False`、`echo=True`；不改变胜负；可被撕、可被折、可被挤。
- 验回声：日志 `("caught", i, text, "echo")`；`echo_caught=True`；`door_read=1`；撕掉该页。
- C 结局优先级：折起且非原话页（`folded and not real`）> 回声页 > 第一个非 real 页。
- A/B 只在 `echo_caught` 时加 coda；`CODA["A"]` 已改为「你手上那张，不一定是留给你的——这叠纸现在是所有人的。」
- 回声相关文案统一为「有人留在门缝里的那句」「别人留下的话」，不再写「上一局你」「上一个你」。

### 4.8 回执打标

`finish()` 计算：

```python
duration = f"{elapsed // 60} 分 {elapsed % 60} 秒"
wake_usage = f"走 {walk} · 写 {write} · 抄 {copy} · 验 {verify} · 展开 {unfold}"
door_usage = f"路过 {door_reached}·有纸 {door_letter}·读过 {door_read}"
unlocated = len(self.unlocated)
```

- `door_reached` 每次进入 (2,2) +1。
- `door_letter` 第一次看到门缝有纸，或 `看` 读到纸时置 1。
- `door_read` 读到/验到门缝回声时置 1；是布尔语义，不累加。
- 时长含挂机，只作事实；不进结局、不加分、不判人。

### 4.9 结局文本

- 七结局判定 `ending()` 一行未改。
- `ENDINGS["E"]` 数字行加入 `{unfolded}`：

  > 「…{used} 次醒来用来走路，其中 {unfolded} 次展开了一页折痕…」

- C 折叠变体只对非原话页使用；折起的真页（原话/自己的字）不会被当成「不是你写的」展示。
- `C_FOLD` 用 `{gist}`，不承诺大意等于原文。

### 4.10 CLI

```
python notebook_v05.py [--seed N] [--debug] [--plain]
  [--name 谁] [--echo auto|always|never]
  [--receipt PATH] [--no-receipt] [--door PATH]
  [--no-fold] [--version]
```

- `main()` 传 `fold=True`；`--no-fold` 关。
- TTY 默认开回执 + 门缝；非 TTY 默认关。
- `--receipt PATH` 非 TTY 也强制开启；缺 PATH 时静默回落。
- `--no-receipt` 优先：回执、门缝、留话、回声全关；折叠/没记仍生效。
- `--door PATH` 只覆盖单文件路径、不单独开启；`--inbox DIR` 走跨机器目录，两者同时给时 inbox 优先；门缝跟随回执开关。
- `--pool PATH` 换原话池；`--strict-content` 在占位池上退出 2。
- `--echo` 非法值回落 `auto`。
- `--version` 打印 `本子 v0.5` 并退出。

### 4.11 命令

新增：

- `展开 <页码>` / `unfold <页码>`：花 1 次醒来。
- `没记 <话>` / `未定位 <话>` / `note <话>`：免费。
- 开场白与帮助补「展开」「没记」，并说明「走、写、抄、验、展开各花一次；看和没记不花」。

## 八、与 `01-架构-v0.5.md` 的偏差

1. **没有单独公开 `fold()` 方法**：折叠逻辑在 `Notebook._fold_oldest()`，由 `next_round()` 调用。对外行为与架构一致；测试通过 `next_round()` 触发。
2. **页字段初始即含 `folded/ever_folded/full_text/gist`**：值分别为 `False/False/None/None`，对旧逻辑无影响。
3. **`report()` 新增「未定位 N 条　用时 X 分 Y 秒」**：架构只要求回执四行，未规定 report 形式，属实现补充。
4. **`--name` 在回执里截断到 20 字**：架构未写长度，按 01b 的 20 字上限实现。
5. **`finish()` 写门缝使用 `DoorStore.append()`**，与回执写入同一处；架构只要求「同时写」，未规定先后。
6. **`unfold` 是独立公开 API/命令**，内部自己 `check_end()` + `next_round()`；架构说「推进回合」，实现把推进放在 `unfold` 内，`play()` 不重复推进。

## 十、风险与待拍板

1. **`退` 不写回执**：`play()` 的退出分支直接 `return`，不经过 `finish()`，所以不留话、不写回执、也不写门缝。v0.4.1 就如此；如果希望「退」也算一局，应改为 `finish()` 后返回。demo 已规避。
2. **`--echo always` 不是绝对**：没有回执/门缝、或来源为空时，`echo_text=None`，即使 `echo_wake` 命中也不会推回声页。想做成「总是有回声」需要合成兜底文本，属于内容决策。
3. **折叠大意的截断风险**：`gist` 是前 12 字硬截断，断在「不」字前可能读成相反意思；C 折叠变体只显示大意，不承诺等于原文。这是剧本接受的设计，但玩家可能误解。
4. **`--door` 依赖回执开关**：非 TTY 下只给 `--door` 不会开启门缝；`--no-receipt` 永远优先。如果希望门缝独立开关，需要新增参数或改语义。
5. **门缝并发**：`DoorStore.append()` 是单行追加，通常原子，但没有文件锁；多个进程同时写同一行首可能交错。回执是「读-改-写 + `os.replace`」，并发时后写覆盖先写。单机单人无影响。
6. **折叠开启的胜率口径**：本文 300/300 是「全知最短路线 + 验原话页」的脚本策略；不等于所有玩家策略。朴素策略在折叠下可能明显掉胜率，需在玩法里提醒「先展开再验」的代价。
7. **旧测试 4 条断言已改**：严格意义的「旧 204 项零改动」无法同时满足版本号/叙事文案变更；已把改动压到最小并逐条记录。
8. **`_tmp` 固定目录**：测试并发跑会互相清目录；需要并行时改成带 pid 的子目录。
