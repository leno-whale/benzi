# 《本子》v0.5 玩法

十三次醒来。三页纸。三张原话。后门只认三张原话，也认你亲手验过一页的墨迹。

v0.5 把三件事合在一起：本子会自己折页；原话从一个池子里抽；门缝可以跨机器，一人一份文件。

## 一、怎么玩

在 `v0.5` 目录运行：

```bat
启动-v0.5.bat
```

或直接：

```bat
python notebook_v05.py --inbox 门缝/inbox
```

`启动-v0.5.bat` 默认走跨机器门缝（`门缝/inbox/`）。想用旧式单文件门缝，运行：

```bat
python notebook_v05.py --door 门缝/留话.txt
```

默认在终端里玩；每次输入一个动作，回车。

## 二、动作

| 动作 | 写法 | 花醒来 | 说明 |
|---|---|---|---|
| 走 | `n` / `s` / `e` / `w` | 1 | 北/南/东/西；九间屋，门厅在西南角 |
| 写 | `写 <一句话>` | 1 | 写自己的话；最多 60 字，满页会挤掉最旧的非原话页 |
| 抄 | `抄` / `copy` | 1 | 把当前屋里的原话抄进本子；出了屋就忘，必须抄 |
| 验 | `验 <页码>` / `check <页码>` | 1 | 验墨迹；验假页会撕掉并腾一页；验原话确认它 |
| 展开 | `展开 <页码>` / `unfold <页码>` | 1 | 展开折起页，原文回来；折痕留着，这一页不会再折 |
| 没记 | `没记 <一句话>` | 0 | 记在手边纸上，不占本子页；最多 5 条，超出挤最早 |
| 看 | `看` / `look` | 0 | 看房间、本子、地图；在后门可重读门缝 |
| 退 | `退` / `quit` | — | 结束本局，进入结算 |

`看` 和 `没记` 不花醒来，但也不会推进回合。

## 三、折叠

- 第 **4 / 8 / 12** 次醒来，本子会自己折起**最旧的一页非原话页**（没折过的）。
- 折起后，页上只显示「（折起来的一页。大意：前 12 个字……）」；原文还在，只是看不见。
- 折起页**不能验**；要验，先花一次醒来`展开`。
- 一张纸**只折一次**：展开后不会再折，折痕留着。
- **原话永不折**；折起页被挤掉时按普通页处理。
- 第 12 次醒来如果同时有替写页和折叠，先推替写页，再折。

折叠是主要压力：以前“多写一页”只是多花一次醒来，现在多写的一页还可能被折成一句大意。

## 四、原话池

- 游戏从 `原话池-v1.md` 的 active 条目里抽三张；池子默认 8 条。
- 同一个 seed 抽同一组三张；换 seed 才换组。
- 抽签用的是独立随机流，不会改变房间布局。
- 池子可以只增不改：旧条目标 `retired`，不删、不复用 id。
- 回执只记 `原话池` 版本和三张 `原话 id`，不记原文。
- 池子里是 8 句定稿原话，每句标了 `to: self/other`；每局至少抽到一张写给自己、一张写给别人。
- 池子改内容时只新增，旧条目标 `retired`；`--strict-content` 会拒绝任何占位内容，退出 2。

## 五、门缝、回执、留话

- 每局结束（A–G 任一结局）可以留一句话，最多 40 字；直接回车 = 不留。
- 留话会写进两处：
  - 你自己的 `回执.md`（日期、seed、结局、原话、留话、批注、版本、时长、醒来用在哪、门、未定位、原话池、原话 id）；
  - 门缝：默认 `门缝/inbox/`，一人一份 `<日期>-<署名>-<4位>.md`。
- **门缝是明文**：同一个 `inbox/` 目录下的人都能读到。开局会明说一次。
- 跨机器用法：把 `门缝/inbox/` 放进 OneDrive / Syncthing / NAS / U 盘共享目录即可；代码只读这个目录，不做服务端。
- 读的时候按固定规则取最近一条非空留话：
  1. 文件头 `<!-- t: ISO 时间 -->`；
  2. 文件名里的日期；
  3. mtime 兜底，并标记「时间未知」。
- **mtime 不作为主排序键**：同步盘复制一次就会变，不能代表谁的话最新。
- 一人一份，写时各写各的，绝不改别人的文件；重名不覆盖，用 4 位随机后缀区分。
- 读状态记在 `门缝/inbox/.read/<署名>.json`，只记在读的人这边。
- 下一局开始，替写者可能把**最近一条非空门缝留话**原文抄进某张假页，成为“回声页”；默认 50% 概率。
- 回声只取留话第一行；回声页仍是假页：不改变胜负，撕掉后照常腾一页；它可以被折。
- 验到回声页：会认出“这是有人留在门缝里的”；这一局结束时的留话会变成“回那个人一句”的语气。
- `--no-receipt` 会同时关掉回执、门缝、留话和回声；折叠与`没记`仍然生效。
- 旧的单文件门缝仍可用：`--door 门缝/留话.txt`；它保留 v0.5 的“每行一条、最新在最后一行”读法。

## 六、回执里的新字段

v0.5 的回执在 `- 版本：0.5` 之后多四行：

```
- 时长：X 分 Y 秒
- 醒来用在哪：走 N · 写 N · 抄 N · 验 N · 展开 N
- 门：路过 N · 有纸 N · 读过 N
- 未定位：N 条
```

再往后，如果这一局用了原话池，还会写：

```
- 原话池：原话池-v1
- 原话 id：q03,q05,q08
```

- `时长`只是事实，含挂机，不判人、不给奖励、不进结局。
- `门：有纸` 表示门缝里读到过纸；`读过` 表示真的读了/验了回声。
- `未定位` 是你用`没记`记下的条数，不是本子页。
- `批注` 是给作者后补的，游戏不写、不覆盖。

## 七、命令行

```bat
python notebook_v05.py --seed 7
python notebook_v05.py --no-receipt
python notebook_v05.py --receipt my.md --inbox 门缝/inbox --name 甲
python notebook_v05.py --receipt my.md --door 门缝/我的.txt
python notebook_v05.py --pool 原话池-v1.md --strict-content
python notebook_v05.py --echo always
python notebook_v05.py --no-fold
python notebook_v05.py --version
```

| 参数 | 作用 |
|---|---|
| `--seed N` | 固定布局，也固定同一组三张原话 |
| `--debug` | 显示隐藏纸的位置 |
| `--plain` | 无颜色 |
| `--name 谁` | 回执里的“谁”、门缝文件名里的署名，默认“你/玩家” |
| `--echo auto/always/never` | 回声概率；默认 auto=50% |
| `--receipt PATH` | 回执路径，并开启回执/门缝 |
| `--no-receipt` | 关回执/门缝/留话/回声 |
| `--door PATH` | 旧式单文件门缝 |
| `--inbox DIR` | 跨机器门缝目录；与 `--door` 同时给时 inbox 优先 |
| `--pool PATH` | 原话池文件 |
| `--strict-content` | 占位原话直接拒绝运行（交付前检查） |
| `--no-fold` | 关折叠，回到 v0.4.1 手感 |
| `--version` | 打印 `本子 v0.5` |

## 八、七结局

A–G 判定与 v0.4.1 相同；v0.5 只加折叠页/回声页的文本变体，不新增第八结局。

- A 压痕：赢了，本子里有自己的字。
- B 三张别人的话：赢了，但一句自己的字也没写。
- C 最好听的那一页：输了，本子里还有假页/回声页/折起页。
- D 指缝里的纸：输了，但验出过假页，指缝里留着纸。
- E 差几步：原话齐了，人没回到门厅。
- F 纸外面：原话齐了，本子满了，人在门厅外面。
- G 挤掉的那几页：以上都不是。

## 九、一句话攻略

先抄，再验，留一次醒来给折页；`没记`不占页，该记就记；门缝里的字不一定是你的，也不一定不是。
