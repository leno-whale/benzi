## 摘要

v0.5 在 v0.4.1 的「回执 / 留话 / 回声页」上加了四件 leno 规划里的事：

1. **门缝并档**：所有玩家的留话进同一个 `门缝/留话.txt`，append-only，最新在最后一行；
2. **回执自动打标**：时长、醒来用在哪、门、未定位四行；
3. **折叠**：第 4/8/12 次醒来折起最旧的非原话页，花一次醒来可展开，折起页不能验，原话永不折；
4. **未定位**：`没记`免费、不占页、最多 5 条。

没有新增第八结局，没有挪后门，没有改 `WAKES=13` / `PAGES=3` / 三原话 / 七结局判定。代码为独立 `notebook_v05.py`（1185 行），测试 258 项全过，演示两局通过。

### 4.3 Notebook 状态

```python
Notebook(seed=None, debug=False, receipt=None, name="你", echo="auto",
         door=None, clock=None, fold=False)
```

- `fold=False` 是 API 默认；旧测试 `Notebook(seed)` 行为与 v0.4.1 一致。
- `main()` 传 `fold=True`；`--no-fold` 关闭。
- `receipt=None` / `door=None` 默认不读写；`main()` 才设默认路径。
- `clock` 默认 `time.monotonic`，测试注入固定时钟。

页字段：

```python
{"text", "ink", "real", "piece", "echo",
 "folded": False, "ever_folded": False, "full_text": None, "gist": None}
```

### 4.4 关键顺序

- `next_round()`：回合 +1 → 3/6/9/12 推替写页/回声 → `round % 4 == 0` 折叠。
- 先 push 再 fold：push 可能挤页，fold 只折 push 后仍在的页。
- 第 12 次同时命中假页和折叠：先假页，后折叠。
- `finish()`：结局 → 结算 → 报告 → 留话 → 写回执 → 写门缝 → 提示 basename。

## 七、平衡与可玩性

v0.5 默认 `fold=True`，但折叠只折非原话页；三张原话永不折。因此：

- 原话路线不变：全知 56/300 仍全胜；
- 扫到第三张即回仍 35/56、180/300；
- 走完全程仍 0/56、0/300（成本 13 > 12 的旧结论在 13 次预算下仍成立：全程 10 步 + 3 抄 = 13，刚好耗尽，无法回门厅）。

折叠增加的是「笔记/假页」的成本：想读折起页要花一次展开；不展开也能赢，但本子里的字更少。这是设计意图，不是平衡破坏。

未单独重跑 fold=True 的胜率：折叠不影响原话与门厅判定，机器人不展开时与 fold=False 同路线；人类展开会额外花醒来。报告如实标注，不把 fold=False 的数字冒充 fold=True 的人类胜率。

## 十、风险与未做

1. **一页只折一次**：第 12 次可能无页可折，后半局折叠变稀；接受，不拿「折两次」补。
2. **`ever_folded` 易错**：展开若清标记会变成可折两次；已用测试专跑「展开后再到第 8 次」。
3. **回声可被折**：验回声要先展开，成本更高；写入玩法，不额外补偿。
4. **门缝无锁/无隐私**：同一台机器上的人互相看得到留话；只承认，不假装解决。
5. **时长含挂机**：只作事实，不判人、不给奖励、不进结局。
6. **未重跑 fold=True 人类胜率**：折叠不折原话，机器人不展开时路线不变；人类展开是额外成本。
7. **根目录未提升**：v0.5 是独立版本；如果主人要替换根，需要再做一次提升与根测试。
