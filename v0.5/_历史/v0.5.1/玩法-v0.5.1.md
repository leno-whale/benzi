# 《本子》v0.5.1 玩法

十三次醒来。三页纸。三张原话。后门只认三张原话，也认你亲手验过一页的墨迹。

v0.5.1 只加一件事：原话不再写死在代码里，而是从一个池子里抽。同一个 seed 抽同一组三张；池子可以换内容，不用改程序。

## 一、怎么玩

在 `v0.5` 目录运行：

```bat
启动-v0.5.1.bat
```

或：

```bat
python notebook_v051.py
```

默认在终端里玩；每次输入一个动作，回车。

## 二、动作

| 动作 | 写法 | 花醒来 | 说明 |
|---|---|---|---|
| 走 | `n` / `s` / `e` / `w` | 1 | 北/南/东/西；九间屋，门厅在西南角 |
| 写 | `写 <一句话>` | 1 | 写自己的话；最多 60 字，满页会挤掉最旧的非原话页 |
| 抄 | `抄` / `copy` | 1 | 把当前屋里的原话抄进本子；出了屋就忘，必须抄 |
| 验 | `验 <页码>` / `check <页码>` | 1 | 验墨迹；验假页会撕掉并腾一页；验原话确认它 |
| 展开 | `展开 <页码>` / `unfold <页码>` | 1 | 展开折起页，原文回来；折痕留着，这一页不会再折 |
| 没记 | `没记 <一句话>` | 0 | 记在手边纸上，不占本子页；最多 5 条，超出挤最早 |
| 看 | `看` / `look` | 0 | 看房间、本子、地图；在后门可重读门缝 |
| 退 | `退` / `quit` | — | 结束本局，进入结算 |

`看` 和 `没记` 不花醒来，但也不会推进回合。

## 三、折叠

- 第 **4 / 8 / 12** 次醒来，本子会自己折起**最旧的一页非原话页**（没折过的）。
- 折起后，页上只显示「（折起来的一页。大意：前 12 个字……）」；原文还在，只是看不见。
- 折起页**不能验**；要验，先花一次醒来`展开`。
- 一张纸**只折一次**：展开后不会再折，折痕留着。
- **原话永不折**；折起页被挤掉时按普通页处理。
- 第 12 次醒来如果同时有替写页和折叠，先推替写页，再折。

## 四、门缝、回执、留话

- 每局结束（A–G 任一结局）可以留一句话，最多 40 字；直接回车 = 不留。
- 留话会写进两处：
  - 你自己的 `回执.md`；
  - 共用的 `门缝/留话.txt`（纯文本，每行一条，最新在最后一行）。
- 下一局开始，替写者可能把**最近一条门缝留话**原文抄进某张假页，成为“回声页”；默认 50% 概率。
- 验到回声页：会认出“这是有人留在门缝里的”；这一局结束时的留话会变成“回那个人一句”的语气。
- 回声页仍然是假页：不改变胜负，撕掉后照常腾一页；它可以被折。
- `--no-receipt` 会同时关掉回执、门缝、留话和回声；折叠与`没记`仍然生效。

## 五、原话池

- 池子文件：`原话池-v1.md`。
- 池子里每条有固定 id（`q01`…）；每局抽 3 条，放进三间纸房。
- 同一个 `--seed` 抽同一组；抽签用独立随机流，**不影响布局**。
- 条目只增不删；不要的条目写 `## q07 retired`，不要改 id、不要复用 id。
- 占位池：正文是 `###原话-01###` 这种格子。用它玩时，开局第一行会提示「占位原话」。
- 交付前用 `--strict-content`：池子里还有占位格就直接拒绝运行，退出码 2。
- 回执里会记 `- 原话池：...` 和 `- 原话 id：q01,q04,q07`；**不记原话正文**。旧回执不改写。

回执在 `- 版本：0.5.1` 之后可能有：

```
- 时长：X 分 Y 秒
- 醒来用在哪：走 N · 写 N · 抄 N · 验 N · 展开 N
- 门：路过 N · 有纸 N · 读过 N
- 未定位：N 条
- 原话池：原话池-v1（或 placeholder）
- 原话 id：q01,q04,q07
```

`时长` 只是事实，含挂机，不判人、不给奖励、不进结局。`批注` 是给作者后补的，游戏不写、不覆盖。

## 六、命令行

```bat
python notebook_v051.py --seed 7
python notebook_v051.py --no-receipt
python notebook_v051.py --receipt my.md --door 门缝/我的.txt
python notebook_v051.py --pool 原话池-v1.md
python notebook_v051.py --strict-content
python notebook_v051.py --echo always
python notebook_v051.py --no-fold
python notebook_v051.py --version
```

| 参数 | 作用 |
|---|---|
| `--seed N` | 固定布局，并抽同一组原话 |
| `--debug` | 显示隐藏纸的位置 |
| `--plain` | 无颜色 |
| `--name 谁` | 回执里的“谁”，默认“你” |
| `--echo auto/always/never` | 回声概率；默认 auto=50% |
| `--receipt PATH` | 回执路径，并开启回执/门缝 |
| `--no-receipt` | 关回执/门缝/留话/回声 |
| `--door PATH` | 门缝路径（不单独开启） |
| `--pool PATH` | 指定原话池 |
| `--strict-content` | 占位池拒绝运行（退出码 2） |
| `--no-fold` | 关折叠，回到 v0.4.1 手感 |
| `--version` | 打印 `本子 v0.5.1` |

## 七、七结局

A–G 判定与 v0.4.1 相同；v0.5 只加折叠页/回声页的文本变体，不新增第八结局。

- A 压痕：赢了，本子里有自己的字。
- B 三张别人的话：赢了，但一句自己的字也没写。
- C 最好听的那一页：输了，本子里还有假页/回声页/折起页。
- D 指缝里的纸：输了，但验出过假页，指缝里留着纸。
- E 差几步：原话齐了，人没回到门厅。
- F 纸外面：原话齐了，本子满了，人在门厅外面。
- G 挤掉的那几页：以上都不是。

## 八、一句话攻略

先抄，再验，留一次醒来给折页；`没记`不占页，该记就记；门缝里的字不一定是你的，也不一定不是。
