## 3. 顶层架构

采用 A 方案：**独立数据层 + Notebook 薄钩子**，不继承、不改主循环。

```
原话池-v1.md
   │ load_quote_pool()
   ▼
QuotePool(entries, version, status, placeholder)
   │ select(seed)  ← random.Random(seed + QUOTE_SALT)
   ▼
Notebook.__init__
   ├── hidden[room] = 正文
   ├── hidden_ids[room] = q01…
   ├── quotes = 本局三张
   └── piece_ids[] ← copy() 时与 pieces 对齐
   │
   ├── play()      占位提示
   ├── finish()    回执 pool + quote_ids
   └── main()      --pool / --strict-content
```

关键边界：

- `QuotePool` 不依赖 `Notebook`，可单独单测。
- `Notebook(seed)` 默认读默认池；文件缺失回退内置三张，旧目录不崩。
- 抽原话使用独立 RNG，**不消耗布局 RNG**；这是平衡数字不变的前提。
- `hidden` 仍是 room→正文；`hidden_ids` 是旁路；`copy()` 原有正文逻辑不变，只多记一个 id。

## 4. 实现

### 4.1 池文件格式

```markdown
pool: 原话池-v1
status: placeholder

## q01
###原话-01###

## q07 retired
（这条不参与抽取）
```

- `pool:` 版本；`status: placeholder|active`。
- `## q01` 稳定 id；`## q07 retired` 停用。
- 正文取 `##` 后第一条非空、非 `>`、非普通标题的行；`###原话-XX###` 合法。
- 至少 3 条 active；id 不重复；空正文报错。
- placeholder 状态与正文占位格必须一致，否则报错。

### 4.2 抽取

```python
rng = random.Random(None if seed is None else int(seed) + QUOTE_SALT)
return rng.sample(active, 3)
```

`QUOTE_SALT = 0x01005101`。同 seed 同组；不同 seed 大概率不同；池内容一变，同 seed 的组也会变，这是内容变更的预期。

### 4.3 回执

`make_entry(..., pool="", quote_ids="")` 只在传值时增加两行：

```
- 原话池：placeholder
- 原话 id：q01,q04,q07
```

`_format` 写在版本/四字段之后；`_parse_block` 兼容旧条目（没有这两行也能解析）。`latest_line` 仍只看留话，不受影响。

### 4.4 CLI

新增：

| 参数 | 行为 |
|---|---|
| `--pool PATH` | 指定池文件；解析失败打印原因、退出码 2 |
| `--strict-content` | 占位池拒绝运行，退出码 2 |
| `--version` | `本子 v0.5.1` |

其余参数、TTY/非 TTY 规则、`--no-receipt`、`--no-fold`、`--door`、`--echo` 与 v0.5 一致。

### 4.5 兼容

- 旧 258 项全过；`PIECES` 常量保留作无池文件回退。
- 旧测试手动构造 `g.pieces` 时没有 `piece_ids`，`finish()` 不写 id 行，不报错。
- 旧回执没有 `原话池/原话 id`，解析照常。

## 10. 风险与未做

1. **占位池不是成品文本**：规则可玩，内容仍是占位；这是按「不替你写原话」的边界做的。填内容前，开局会明确提示。
2. **同 seed 的组会随池内容变**：这是内容变更，不是布局 bug；布局仍稳定。
3. **id 纪律靠人**：解析器只查重、查空、查 retired；改历史 id 无法自动阻止。
4. **折叠胜率未重跑**：本版不改折叠，但也不声称折叠后的平衡数字。
5. **跨机器门缝未做**：按 leno 决定留到 v0.6。
