# 《本子》v0.5.1 顶层架构：原话池

版本：0.5.1  
范围：只把「三张原话」从代码常量改成可替换的数据池；不改玩法、不改结局、不改根目录。  
基线：`v0.5/notebook_v05.py`（v0.5.0，258 项测试）。

## 1. 一句话

保留 v0.5 的 `Notebook` 主循环和所有结局判定，只替换「三张原话从哪里来」：新增独立的 `QuotePool` 数据层，用独立随机流按 seed 抽 3 条，再把 id 带进回执。

## 2. 模块

```
原话池-v1.md
   │  load_quote_pool()
   ▼
QuotePool（entries / version / status / placeholder）
   │  select(seed)  ← 独立 RNG：seed + QUOTE_SALT
   ▼
Notebook.__init__
   ├── hidden[room] = 原话正文
   ├── hidden_ids[room] = q01…
   └── piece_ids[] ← copy() 时与 pieces 对齐
   │
   ├── play()      占位池开局提示
   ├── finish()    回执写 pool + quote_ids
   └── main()      --pool / --strict-content
```

不新增 `Notebook` 子类，不改 `DoorStore`、`ReceiptStore`、折叠、回声、七结局。

## 3. 数据格式

```markdown
pool: 原话池-v1
status: placeholder

## q01
###原话-01###
```

- `## q01` 是稳定 id；`## q07 retired` 表示停用，不删、不复用。
- 正文取 `##` 后第一条非空、非 `>`、非普通 Markdown 标题的行；`###原话-XX###` 是合法占位格。
- `status: placeholder` 与正文占位格必须一致：标了 placeholder 却全是真话、或没标却含占位格，都报错。
- 至少 3 条 active；id 不重复。

## 4. 关键决定

### 4.1 独立随机流

`QuotePool.select(seed)` 用 `random.Random(seed + QUOTE_SALT)`，在 `Notebook` 布局 RNG 之外抽 3 条。  
**理由**：v0.5 的 56 布局/300 种子平衡数字必须逐字节保持；抽原话不能消耗 `self.rng`。

### 4.2 默认与 strict

- `Notebook(seed, ..., quote_pool=None)`：默认读 `v0.5/原话池-v1.md`；文件缺失时回退内置三张，旧测试/旧目录不崩。
- `strict_content=True` 或 CLI `--strict-content`：占位池直接 `ValueError`；CLI 捕获后打印原因、退出码 2。
- 普通游玩只提示，不阻止：作者还没填池时也能试玩。

### 4.3 回执只记 id

- `make_entry(..., pool="", quote_ids="")`：只有传值才加两行，旧调用/旧断言不变。
- `finish()` 写 `pool=placeholder|原话池-v1`，`quote_ids` 取 `piece_ids`（抄写顺序）。
- 回执不写原话正文；旧回执不迁移、不改写。

### 4.4 兼容边界

- `PIECES` 常量保留，作为无池文件时的回退；v0.5 旧测试仍可跑。
- `hidden` 仍是 room→正文；`hidden_ids` 是新增旁路，不改变 `copy()` 对正文的处理。
- 手动构造 `g.pieces` 的旧测试没有 `piece_ids` 时，`finish()` 不写 id 行；不报错。

## 5. CLI

| 参数 | 行为 |
|---|---|
| `--pool PATH` | 指定池文件；解析失败打印原因、退出码 2 |
| `--strict-content` | 占位池拒绝运行，退出码 2 |
| `--version` | `本子 v0.5.1` |

其余参数与 v0.5 完全一致。

## 6. 测试矩阵

新增「原话池」组（17 项）：

- 默认池 8 条 active、placeholder、版本；
- 同 seed 同组、3 条不重复、不同 seed 可不同；
- `strict_content` 拒绝占位池；
- `copy()` 记下 `piece_ids`；
- `retired` 跳过；
- `status: active` 含占位格报错；
- `make_entry`/`_format`/`_parse_block` 的 pool + id 往返。

回归：v0.5 的 258 项全过；另跑 200 个 seed 的 hidden 房间对比，0 差异。

## 7. 风险

1. **占位池被误当成品**：已用开局提示 + `--strict-content` + 测试三层挡；但人若忽略提示仍可玩，这是有意的「可试玩」。
2. **池子 id 被改/复用**：解析器只能查重，不能阻止作者改历史 id；文档写死「只增、retired、不复用」。
3. **同 seed 跨版本稳定**：v0.5.1 的抽签独立，布局稳定；但如果以后改池子内容，同 seed 的「哪三张」会变，这是内容变更的预期，不是 bug。
4. **回执旧条目无 pool/id**：解析器保持可选字段，`latest_line` 只看留话，不受影响。
