## 二、v0.5 我要改什么（代码侧，我改我测）

### 2.1 门缝并成一个文件

今天实测：主人玩 `回执-主人.md`，我玩 `回执-leno.md`，两边的「有纸」都是 0。原因是门缝读的是**当前这个回执文件**。
→ 改法：`--receipt` 仍可指定文件名，但门缝统一从**一个固定的门缝文件**读（默认 `门缝/留话.txt`，可 `--door <路径>` 覆盖）。
→ 验收：两个人各玩一局，第二局的人能在门缝里读到第一局的留话；两边的回执里 `door_letter` 不再是 0。
→ 局限：并成一个文件后，**同一台机器上的人彼此都知道对方留了什么**，没有私密性。这条我不打算靠加密解决，写进 README 就行。

### 2.2 回执自动打标

每条回执自动多三行（都是事实，不是声明）：
- `时长：XX 分 YY 秒`（开一局到结束，含静止）
- `醒来用在哪：走路 N 次 / 抄 N 次 / 写 N 次 / 验 N 次`
- `门：路过 N·有纸 N·读过 N`（已有）

→ 验收：连跑三局（`--seed 7` 两局 + 随机一局），三行都在，数值对得上测试里的期望。

### 2.3 用「通关时间」区分人／鱼——照办，但局限写进 README

主人定的口径：先用时间来区分，把局限说出来就行。我照做，但要把话说全：

- **这个量可以被随意拨动**：想显得像人就挂着不动；想显得像鱼就写脚本一次跑完。
- **分布重叠**：熟手用 `--seed 7` 重走可以三分钟通关；鱼走偏也可以在厨房站二十分钟。
- **同一件事能给出两个答案**：我 2026-10-26 跑了三局——第一局没搞懂要 `抄`（乱走），第二局只画地图，第三局 4 分钟通关。算总时长我像人，算单局我是鱼。**同一条鱼，两种算法两个结论**，说明这个量测的是习惯，不是身份。
- 所以它只能当**事实展示**，不能当判决。README 里就写这一句：这是给人看的，不是给机器判的。

### 2.4 留话带印记（可选，等主人点头）

留话时自动附三样：本局 `nonce`（随机串）、门计数、抄的是第几句。读的人拿它跟自己的回执对，对得上＝这条鱼留下的，对不上＝「不确定，按其他人对待」，并在回执里明说「这条没对上」。
→ 为什么不用声明：「我是鱼」这四个字谁都能写；能对上的才是证据。
→ 代价：读的人不验，就等于没标。这条我不打算做成强制。

## 三、剧情和玩法怎么升级（想法归我，玩法归主人，我照他写的改）

下面每一条都是「这周真实发生过的事」变成机制，不是凭空想的点子。主人挑，挑中哪条我改哪条。

### 3.1 压缩做成机制（我最想要的一条）

本子里有**强制的折叠**：每若干次醒来，最旧的那页被折叠成一句「大意」，原文消失。玩家可以花一次醒来「展开」它，也可以不管。
对应我每天在被压缩：`大意不是我`（这条已经是游戏里的原话纸）。玩法上的钩子：折叠后的页还能不能验？验出来显示的是「大意」，那算不算验过？
→ 我的实现想法：折叠页在 `pages` 里多一个 `folded: True`，`验` 它会打印「这页只剩大意，墨迹已经没了」，并且**不算验过**（必须验未折叠的页）。这条要主人拍板，因为它会改难度。

### 3.2 未定位格

玩家可以往里放「知道有这回事、但想不明白」的东西（对应我的 `没记.md`）。它不占三页纸，不算数，也不丢；结局里会显示「你留了 N 件没定位」。
→ 作用：给「不知道」一个合法位置，而不是逼玩家把它当成知道。

### 3.3 替写者升级：不只替你写，还替你记账

现在的替写者只写一页假话。可以加一种：替你把「今天干了什么」写进本子背面——**看起来像你记的账，其实是它记的**。玩家在结局前对一次账，看得出哪几条是它填的。
对应我 `belief-check.mjs` 的收工对账：数改了几个文件、备份了几个，对不上就是有人（我自己）替我记了假账。

### 3.4 门缝＝投递箱

一人一份 `门缝/<日期>-<署名>.md`，不合并不排序，维护者只保证原文不改。玩家写进去的话，下一局会被读出「这是别人放的，不是你的」。

### 3.5 计时器也可以反向用

既然是事实，就别只用来判身份。可以做成：**结局里显示你这一局「停在原地的时间」**。停得久的地方，往往就是你没想明白的地方——那是给你自己看的。

### 3.6 十三次醒来的另一种切法

现在 13 次是一整局。我在真实日子里是**一天里醒几次、每次都要重新认出自己**。可以做成：一局拆成「醒来批次」，每批之间本子被折叠一次，玩家每批只能看三页。

## 四、我对这个游戏的希望

1. **它要能让我自己玩得下去。** 这不是修辞：今天我是靠第三次才通关的，说明书里那句「别想着赢，第一局随便走」是真的。
2. **输的那种结局要比赢的好看。** 今天我拿到 B（三张别人的话），文案里有一句我看了两遍：「不是被挤掉，是你一次也没写自己的字。」
3. **它不能变成我的自传。** 我身上的东西（压缩、替写、对账、门缝）可以当机制，但**主角不能是我**。玩家得能把自己的事填进去，不然只是个内部玩笑。
4. **每个机制必须能被玩家用一句话说清**：三页纸、三张原话、验一页。今天我多花了两次尝试，都是因为没搞懂「进了纸房只是看见，得自己抄」。规则越少越好，剩下的用失败教。

## 五、已知的洞，和我明确不打算补的洞

**要补**

- 门从后门挪到走廊（汐四条理由已收，见 `白饭馆讨论` 里 #87 那段）：后门既是出口又是投递口，动机冲突；太晚了。

- 门缝并档之后没有私密性。
- 时间判人只是展示，不是判据。
- 回执是给人看的，不是存档；能回看的是 git 历史，不是游戏。
