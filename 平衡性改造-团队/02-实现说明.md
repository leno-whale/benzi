## 3. `copy()` 的精确顺序

```python
def copy(self):
    if self.pos not in self.hidden:          # 1. 无纸：提示，返回 False
        print(... "这里没有纸可抄。")
        return False
    piece = self.hidden[self.pos]            # 2. 取出文本（不删除）
    if not self.push(piece, piece=True):     # 3. 先尝试落页；失败则提示，返回 False
        print(... "没地方抄。")
        return False
    self.hidden.pop(self.pos)                # 4. 落页成功后才从 hidden 移除
    self.pieces.append(piece)                # 5. 才计入已抄
    self.log.append(("copy", self.round))    # 6. 才写 log
    print("你把这句话抄进本子：" + 原文)      # 7. 成功提示，返回 True
    return True
```

关键点：`push` 在 `pop` 之前 —— 防御分支（三页全原话）失败时 `hidden` 原封不动，不会出现「纸没了但没抄进去」。成功路径的顺序固定为 `push → hidden.pop → pieces.append → log.append`，任何一步失败都不会消耗醒来（`play()` 只看返回值决定是否 `next_round()`）。

## 6. 遗留风险与注意

1. **两种「扫荡+抄」必须分开说**：扫到第三张就回 = 56 布局 35/56、300 种子 180/300；走完全程 10 步再回 = 成本 13，0 胜。文档/口头不要混写，否则会被误读成「62.5% 与 0 矛盾」。
2. **两条盲搜路线的输局集合不同**：`nneeswseww` 的 21 种输局第三张在 (2,0) 锅炉房；8 步哈密顿 `nneesswn` 的第三张在 (1,1) 客厅。两者都是 35/56，但输局集合不同，测试注释不要混写。`nneeswse`（第 8 步到门厅、漏 (2,0)）是错路线，不要用。
3. **parity 论证只是 sanity check**，不是最优性证明；不要写成「已证明所有自适应策略都只有 62.5%」，上界以 POMDP 数字为准。
4. 12 次预算对 8 步布局只余 1 次（成本 11），没有误点容错；这是拍板接受的取舍。
5. 第 12 次醒来若三页全原话，假页 `push` 失败且不写 `("fake",12)` log —— 边缘情况，不影响七结局判定（C 仍由任意非真页触发），但排查 log 时会少一条 fake 记录。
6. `copy()` 的防御分支在正常游戏中不可达（只有三张原话、三页上限），仅由构造状态测试覆盖。
7. 根工作树当前为领航员提升后的 dirty 状态（README/demo/notebook/test/玩法 均有 M，`tools/push.mjs` 是原有 M，未触碰）；**尚未 commit**，是否提交需作者拍板。
