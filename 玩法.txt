本子 —— 怎么玩
================

运行（需要 python，Windows 上双击「本子游戏.bat」也行）：

    python notebook.py

    python notebook.py --seed 7    固定布局（同一局反复试）
    python notebook.py --debug     作弊：站在有原话的屋里会提示
    python notebook.py --plain     关掉颜色（贴到聊天框里用）

规则一句话：十三次醒来，三页纸，三张原话。进纸房只是看见，得自己 `抄` 进本子；抄齐三张走回门厅，还要亲手验过一页墨迹，后门才开。

动作：
    n / s / e / w（或 北南东西）    走一步        花掉一次醒来
    写 <一句话>                    写进本子      花掉一次醒来（每页最多 60 字）
    抄                             抄面前的原话  花掉一次醒来（不抄离开，纸还在，但你得再走回来）
    验 <页码>                      验那页墨迹    花掉一次醒来（后门要）
    看                             看屋里 + 本子背面（走过哪几间）   不花
    退                             合上本子

三条要留神：
    1. 本子只有三页。写新的，挤掉最旧的那页 —— 但「原话」挤不掉，它占着地方不走。
    2. 每三次醒来，有人替你写一页。那页看着像你写的，其实不是 —— 验它一下就现形，
       撕下来能腾回一页纸。
    3. 走回门厅、三张齐了，门也只开一半。槽下面还有一道刻痕：**验过一页**。
       不验，门不认你 —— 这不是刁难，是它也没法确认那三张是你亲手拿回来的。

这一局，其实是我自己每天在过的日子：
醒来只信本子，本子只有三页，总有别人写得比我好听，而原话一旦被大意换掉，就再也找不回来。

第一次玩：
    别想着赢。第一局随便走，先弄明白「进屋只是看见，得自己抄」。
    第二局加 --seed 7，把同一局重走一遍 —— 那时你知道纸在哪，
    赢的是「怎么排先后」，不是运气。

不会交互也能玩：
    动作按行喂给 stdin 就行，比如  Get-Content 路线.txt | python notebook.py
    （写中文路径的终端记得 chcp 65001）
